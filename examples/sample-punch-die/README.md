# 샘플 논문: 재질별 성형해석을 통한 펀치·다이 간극 및 치수 결정

이 시스템이 어떻게 쓰이는지 보여 주는 **박사학위논문 샘플**입니다.

| 장 | 내용 | 상태 |
|----|------|------|
| 1장 서론 | 연구 배경·목적·연구 문제 (인용 포함) | 초안 |
| 2장 이론적 배경 | 전단가공 원리, 간극 이론, 치수 결정식, 성형해석 이론 + 2D 개념도·Blender 3D 그림 | 초안 |
| 3장 연구 방법 | 해석 조건 틀 | 틀만 |
| 4장 연구 결과 | 공구 치수·하중 **계산값** + 간극별 결과 그래프(**예시 데이터**) | 샘플 |
| 5·6장 | 논의·결론 | 빈칸 |

- 참고문헌은 실제 교재·논문이지만 **쪽수·판은 원문 확인 필요**(TODO 표시)
- `sources/data/*예시*.csv` 와 4장의 그래프·적정 간극 표는 **가상의 예시 데이터**입니다. 실제 연구에 그대로 쓰면 안 됩니다.
